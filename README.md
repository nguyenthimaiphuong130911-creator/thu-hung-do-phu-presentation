# Thu Hứng – Đỗ Phủ | Không gian thuyết trình văn học

Website thuyết trình chuyên sâu về bài thơ **Thu hứng (bài thứ nhất trong chùm Thu hứng)** của Đỗ Phủ.

## Nội dung
- Chân dung tác giả và bối cảnh lịch sử – sáng tác
- Nguyên tác chữ Hán, phiên âm Hán Việt và diễn nghĩa
- Giải thích nhan đề, bố cục và mạch cảm xúc
- Phân tích lần lượt tám câu thơ, hệ thống hình tượng và nghệ thuật
- Giá trị nội dung, nghệ thuật, sơ đồ tư duy và gợi ý thuyết trình
- Quiz tương tác có chấm điểm và giải thích

## Chạy website
Đây là website tĩnh, không cần cài đặt thư viện:
- Mở `index.html` bằng trình duyệt, hoặc
- Bật GitHub Pages trong **Settings → Pages → Deploy from a branch → main → /(root)**.

Sau khi bật Pages, website dự kiến có địa chỉ:
https://nguyenthimaiphuong130911-creator.github.io/thu-hung-do-phu-presentation/

## Tùy chỉnh
- Nội dung: `index.html`
- Giao diện và animation: `style.css`
- Tương tác, menu và quiz: `script.js`

Lưu ý: Hình nền đang tải từ Unsplash và font từ Google Fonts nên cần kết nối Internet để hiển thị đầy đủ.
